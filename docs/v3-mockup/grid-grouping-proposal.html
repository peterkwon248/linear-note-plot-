Display properties ↓ 토글해봐 — list면 컬럼, board·grid면 칩으로 켜짐
Display properties = 뷰마다 표현이 다름. List는 프로퍼티 = 컬럼, Board는 카드 위 칩. Grid도 board와 같은 카드 표면이니까 같은 칩 시스템 공유 — 위에서 Priority/Label/Tags/Links/Updated 토글하면 grid 카드에 board와 똑같은 칩이 떠.
카드가 좁으니 칩은 최대 4개 + "+N"로 캡 (board의 PropertyChipRow와 동일). 섹션 헤더 chevron 클릭 = collapse (확정).
