노트가 지식 그래프가 됩니다.

기본은 잔잔하게, 필요할 땐 강력하게.

Plot은 노트와 개인 위키, 지식 그래프를 하나로 묶은 로컬 퍼스트 앱입니다. 겉은 애플 노트처럼 단순하고, 속은 제텔카스텐 — 생각을 잇는 팔란티어 × 제텔카스텐.

P Plot

쓰기만 하세요. 제텔카스텐은 Plot이 대신합니다 — 노트를 잇고, 고립 노트를 찾아내고, 자랄수록 더 쓸모 있어지는 그래프를 키웁니다.

복리처럼 불어납니다. 노트가 10개일 땐 이을 게 별로 없지만, 100개가 되면 새 노트 하나가 기존 여러 개와 맞물립니다.

방법론

제텔카스텐이 뭔가요?

독일 사회학자 니클라스 루만이 쓰던 메모 상자(Zettelkasten)에서 온 방법입니다. 작은 노트를 서로 잇기만 했는데, 9만여 장이 모여 70권이 넘는 책이 됐습니다. 핵심은 단 셋입니다.

01
작게 쪼갠다

한 노트엔 하나의 생각만 담습니다. 작을수록 다시 꺼내 쓰고, 다른 노트와 잇기 쉽습니다.

02
연결한다

노트를 폴더에 가두지 않고 노트끼리 잇습니다. 한 노트가 여러 맥락에 동시에 살아 있게 됩니다.

03
자라난다

구조를 미리 짤 필요가 없습니다. 연결이 쌓이면 미처 몰랐던 생각의 갈래가 저절로 떠오릅니다.

문제는, 이걸 손으로 하면 고됩니다 — 링크를 일일이 걸고, 끊긴 노트를 찾아다니고, 전체 그림을 머릿속에 담아야 하니까요. 바로 그 수고를 Plot이 덜어 줍니다.

쌓아두기가 아니라, 생각하기 위해

다른 노트앱은 한꺼번에 해내지 못하는 7가지

아래 기능은 전부 지금 앱에서 동작합니다 — 로드맵 속 약속이 아니라 코드로 검증된 것들입니다.

세이버메트릭스가 있는 그래프 엔진

단순한 백링크 패널이 아닙니다. 노드가 서로 밀고 당기는 그래프 위에 지표까지 계산합니다 — Knowledge WAR, 2홉 Concept Reach, 클러스터 응집도, 고립 비율. 노트마다 야구 기록 같은 점수가 붙습니다.

노트가 위키로 자랍니다

노트가 원재료라면 위키 문서는 잘 다듬은 완성본입니다 — 인포박스, 내비박스, 백과사전식 레이아웃까지. 촘촘히 연결된 노트는 Plot이 위키로 키우라고 먼저 권합니다.

모든 것에 하나의 워크플로우

4단계 상태(대기 → 준비 → 정리 중 → 완성)와 5단계 우선순위가 노트·위키·북에 똑같이 적용됩니다. 지식 관리에 그대로 옮겨 온 리니어식 프로젝트 흐름입니다.

모든 엔티티를 가로질러 정리

스티커는 종류를 가리지 않고 묶고, 북은 엔티티를 넘나드는 순서 있는 읽기 묶음입니다. 카테고리는 부모를 여럿 둘 수 있는 DAG를 이룹니다. 부모 하나짜리 페이지나 밋밋한 태그와는 차원이 다릅니다.

리니어급 뷰 엔진

리스트·보드·그리드·타임라인에 약 25가지 그룹화, 3단계 다중 정렬, 그룹 접기 기억, 저장된 뷰, 뷰로 굳힐 수 있는 필터 칩까지. 할 일 관리 도구가 아니라 모든 엔티티에서 씁니다.

모든 신호를 받는 하나의 인박스

리마인더, 간격 반복 복습, 위키 레드링크, 미연결 멘션, 본문 속 할 일, 코멘트, 그래프 정비 제안까지 — 미루거나 지우는 하나의 줄로 모입니다.

영원히 비공개, 오롯이 내 것

모든 데이터는 기기 안 IndexedDB에 담깁니다. 백엔드도, 계정도, 몰래 수집하는 정보도 없습니다. 통째로 JSON 백업, 마크다운 내보내기, 서명된 자동 업데이트까지.

사용 흐름

노트에서 지식까지, 실제 화면으로

Plot이 실제로 어떻게 굴러가는지, 핵심 흐름 셋.

흐름 01

노트가 위키로 자랍니다

흩어진 노트를 쓰고 [[위키링크]]로 잇다 보면, Plot이 위키로 키우라고 권합니다. 그때 노트 몇 개를 골라 한 편의 문서로 묶으면 됩니다.

  • 1노트를 쓰고 [[ ]]로 서로 링크 — Plot이 백링크를 자동 추적합니다.
  • 2백링크 3개·200자가 넘으면 인박스 발견에 "위키로 키울까요?" 제안이 뜹니다.
  • 3노트 여러 개 선택 → 액션바의 Wiki → 노트가 참조 블록으로 박힌 새 문서. 원본은 그대로.

위키 공간 — 컴파일된 문서, 카테고리, 성장 차트.

흐름 02

무엇이든, 내 방식대로 봅니다

노트도 위키도 북도, 모든 엔티티가 같은 뷰 엔진을 거칩니다. 네 가지 뷰 모드에 풍부한 그룹화·정렬·필터로 원하는 대로 펼쳐 봅니다.

  • 1리스트·보드·그리드·타임라인 — 디스플레이 패널에서 한 번에 전환.
  • 2약 25가지 그룹화와 3단계 다중 정렬, 보이는 속성 칩을 토글.
  • 3필터 칩으로 좁힌 화면을 Save로 저장된 뷰로 승격 — 다음에 그대로 복원.

북 보드 뷰 — 뷰 모드 토글, 상태·종류 칩, Smart/Manual/Hybrid.

흐름 03

흐름을 놓치지 않습니다

여러 신호를 Plot이 하나의 인박스로 모아 주고, 홈은 지식 베이스 전체를 한눈에 보여줍니다.

  • 1리마인더·복습(SRS)·위키 레드링크·고립 노트·본문 속 할 일·코멘트가 인박스로 모입니다.
  • 2할 일·되새김·발견 세 묶음으로 분류 — 미루기(1시간/내일/다음 주)나 지우기.
  • 3홈 대시보드에서 노트·위키·북 수와 가장 연결된·많이 본 항목을 한눈에.

홈 — 지식 베이스 한눈에 보기.
